# Machina Practica

Disciplined, repeatable agent-assisted software development, grounded in precise intent and observable evidence.

[Practica](https://github.com/machinapractica/practica) brings together **Effective Agents**, a guide for human programmers, and **Machina Practica**, the method and executable workflows for agents and their maintainers.

[Packages](https://github.com/machinapractica/packages) is the home for proposed `@machinapractica/*` implementation mechanics. The ecosystem is pre-release: books, skills, and packages are still being developed or proposed.

Canonical website: [machinapractica.com](https://machinapractica.com).
